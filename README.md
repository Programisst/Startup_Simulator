# Startup Simulator

Симулятор технологического стартапа. Описание игры и план — в папке [docs](docs/).

## Как запустить

Нужен установленный Node.js версии 20 или новее.

```
npm install      # один раз, после скачивания проекта
npm run dev      # запустить игру, откроется адрес http://localhost:5173
npm test         # запустить тесты
npm run share    # собрать игру в один файл share/StartupSimulator.html, который можно переслать
```

Пробная квартира основателя (шаг 1 нового вида игры): после `npm run dev` откройте
http://localhost:5173/room.html. Для проверок: `?time=21:30` — начать вечером, `?speed=4` — ноутбук работает в 4 раза быстрее. `?outfit=shirt` или `?outfit=overshirt` — другой образ героя, `?sheet` — все кадры героя крупно, `?pixel` — старая плоская пиксельная комната.

Выбранный вид квартиры (в работе): http://localhost:5173/concept-lumio.html — пиксель-арт сверху в стиле Lumio. Ходьба WASD или кликом, E — действие, колёсико — ближе или дальше, `?time=13:00` — начать днём.
