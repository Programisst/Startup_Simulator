# Образец 3D-офиса на 12 мест

## Цель
Проверить гладкую объёмную изометрию для этапа smallOffice. Полноценный офис с рабочими местами, переговорной, кухней и зоной отдыха, с живыми мониторами и движением сотрудников.

## Границы
Отдельная страница tools/preview/office-3d.html и автономный HTML в папке вариантов. Источники состава и статусов — SceneTeam. Двенадцать рабочих мест, переговорные стулья считаются отдельно. Восемь сотрудников с закреплёнными seat, четыре свободных места. Устройство офиса оригинальное, референс задаёт масштаб и материалы.

## Планировка
Прямоугольный офис 16×12 метров. У дальней стены — три группы по четыре стола. Справа — стеклянная переговорная, у входа — кухня и мягкая зона отдыха. Центральный маршрут связывает вход, рабочий зал и общие зоны.

## Готовность и проверки
- config.offices.smallOffice.seats → 12 рабочих мест.
- Один ScenePerson.seat → постоянное место, свободные места соответствуют freeSeats.
- Сотрудник отодвигает кресло, встаёт, обходит препятствия и возвращается к своему столу.
- На мониторах — полный редактор Pulse с текущим кодом. Нажатие открывает редактор и браузер на всё окно, Esc возвращает в офис.
- Мышь поворачивает ракурс, колёсико меняет масштаб. Кнопка возвращает исходный ракурс.
- В Chrome без окна проверяются загрузка 3D, управление, монитор, отсутствие ошибок, снимки общего плана и крупного вида.
- npm test и npm run build завершаются успешно.

## Риски
Стеклянные стены могут перекрывать сотрудников. Ближние стены показаны низкими, прозрачные перегородки расположены вокруг переговорной. Крупные экраны требуют достаточно подробной текстуры. Устройства со слабой графикой могут давать меньшую частоту кадров. Сцена ограничена 30 кадрами в секунду и двукратной плотностью пикселей.
